# Application Development Workspace

Reserved for a purpose-built synthetic application that can demonstrate:

- Codebase understanding
- Feature planning and implementation
- Bug reproduction and root-cause analysis
- Test generation and quality improvement
- Refactoring, modernization, accessibility, and performance

The future application should be small, deterministic, offline-capable, free of secrets, and validated with one documented command. Include seeded issues and known expected outcomes without mirroring a real system.
