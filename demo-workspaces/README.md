# Demo Workspaces

These directories reserve locations for small, deterministic, synthetic demonstrations. They intentionally contain guidance only.

- `application-development/` for code understanding, features, bugs, tests, and refactoring
- `infrastructure-as-code/` for review, validation, policy, and safe planning
- `data-and-automation/` for synthetic transformations and workflow automation
- `documentation-and-analysis/` for requirements, documentation, and knowledge workflows

Each future workspace must include setup instructions, validation commands, a known starting state, a fallback, and a data review. Do not copy an engagement repository into this directory.
