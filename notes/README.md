# Notes

This directory is for sanitized, reusable engagement records.

- `decisions.md` records boundary, workflow, and template decisions.
- `action-items.md` records role-based follow-up.
- `parking-lot.md` records unresolved generic topics.
- `sessions/` holds session notes created from `templates/session-notes.md`.

## Rules

- Use roles instead of names.
- Omit customer, program, site, system, tenant, endpoint, and account identifiers.
- Do not paste transcripts, screenshots, logs, source code, tickets, or internal documents.
- Summarize feedback generically and retain detailed records only in an approved system.
- Review notes before every commit.
