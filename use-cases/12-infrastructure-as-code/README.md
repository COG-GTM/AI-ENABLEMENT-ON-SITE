# Infrastructure as Code

## Outcome

Explain and improve synthetic infrastructure configuration using static, local, and non-deploying validation.

## Candidate demo

- Map modules, variables, outputs, and dependencies.
- Review a fabricated change plan.
- Identify policy, security, or maintainability concerns.
- Refactor a small module.
- Run format, syntax, and policy checks locally.

## Evidence

Static checks pass, the expected plan difference is explained, and no real infrastructure is contacted.

## Guardrails

Do not use real state, account identifiers, credentials, endpoints, cloud CLIs, apply commands, or destructive operations.
