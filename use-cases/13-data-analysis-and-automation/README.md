# Data Analysis and Automation

## Outcome

Transform a fabricated dataset or automate a local repetitive task with validated, deterministic, and inspectable logic.

## Candidate demo

- Define schema, constraints, and expected output.
- Validate and summarize synthetic input.
- Implement a local transformation or report.
- Add tests for malformed and boundary values.
- Compare output with known expectations.

## Evidence

Input validation is explicit, results are reproducible, tests cover error cases, and output contains no sensitive values.

## Guardrails

Use small synthetic datasets. Do not query real databases, external APIs, shared drives, mail, or production storage.
