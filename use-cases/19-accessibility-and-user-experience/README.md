# Accessibility and User Experience

## Outcome

Identify and correct a focused accessibility or usability issue in a synthetic interface with standards-based, testable evidence.

## Candidate demo

- Review semantics, keyboard flow, labels, contrast fixtures, and error states.
- Map findings to approved accessibility criteria.
- Add automated checks where meaningful.
- Implement one focused correction.
- Validate with both tooling and human review.

## Evidence

The finding is reproducible, the criterion is cited accurately, automated checks pass, and manual review is documented.

## Guardrails

Do not use real user analytics, recordings, support tickets, identities, or accessibility needs. Do not claim automated tooling proves full conformance.
