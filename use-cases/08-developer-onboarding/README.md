# Developer Onboarding

## Outcome

Help a new engineer safely orient to a repository, configure an approved local environment, and complete a small first task.

## Candidate demo

- Build a repository map and glossary.
- Verify setup steps and local commands.
- Identify contribution and review rules.
- Recommend a bounded first issue.
- Create a checklist that points to source material.

## Evidence

A reviewer can follow the setup, run validation, explain the main code path, and locate relevant ownership guidance.

## Guardrails

Do not expose team rosters, internal account procedures, endpoints, credentials, or broad filesystem context.
