# Refactoring

## Outcome

Improve structure, clarity, or maintainability while preserving externally observable behavior.

## Candidate demo

- Identify duplication or unnecessary complexity.
- Establish characterization tests.
- Propose a small refactor with explicit invariants.
- Apply the change in reviewable steps.
- Compare behavior and validation results.

## Evidence

Tests pass before and after, public behavior is unchanged, and complexity or duplication is measurably reduced.

## Guardrails

Avoid broad rewrites, unrelated formatting, dependency changes, or interface changes unless they are explicit acceptance criteria.
