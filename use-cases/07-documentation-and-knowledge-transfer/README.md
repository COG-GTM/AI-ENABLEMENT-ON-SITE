# Documentation and Knowledge Transfer

## Outcome

Produce accurate, source-grounded documentation that helps an engineer understand, operate, or change a synthetic system.

## Candidate demo

- Compare existing documentation with source.
- Generate a code-path explanation, setup guide, runbook, or decision summary.
- Cite files and commands.
- Identify uncertainty and stale material.
- Validate instructions from a clean starting state.

## Evidence

Commands work, references are accurate, and a reviewer can follow the document without hidden context.

## Guardrails

Do not paste internal documents, transcripts, tickets, architecture, or operational data. Generate purpose-built generic material.
