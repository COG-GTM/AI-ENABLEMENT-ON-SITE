# Codebase Understanding

## Outcome

Explain architecture, ownership boundaries, dependencies, and a targeted execution path with citations to the relevant files.

## Candidate demo

- Inventory a small synthetic repository.
- Trace one request, event, or command from entry point to output.
- Identify tests, configuration, and likely change points.
- Produce a concise diagram or onboarding note grounded in source.

## Evidence

File references are accurate, the path can be verified manually, and uncertainty is explicit.

## Guardrails

Keep the scenario read-only. Scope context to the repository and do not infer unverified production architecture.
