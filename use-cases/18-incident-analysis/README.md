# Incident Analysis

## Outcome

Analyze a fabricated incident dataset to build a timeline, test hypotheses, identify contributing factors, and propose preventive actions.

## Candidate demo

- Normalize synthetic logs and events.
- Build a timestamped timeline.
- Separate observations, hypotheses, and conclusions.
- Trace a failure to synthetic source or configuration.
- Draft corrective and preventive actions.

## Evidence

Every conclusion points to fabricated evidence, uncertainty is explicit, and proposed actions are testable.

## Guardrails

Do not use active incident data, real logs, user identifiers, credentials, network access, or offensive actions. Devin does not replace the approved incident process.
