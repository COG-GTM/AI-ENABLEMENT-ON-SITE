# Security and Compliance

## Outcome

Perform a defensive review of synthetic code or configuration, identify control gaps, and propose verifiable remediation.

## Candidate demo

- Review input validation, authorization, secrets handling, logging, or transport configuration.
- Map a finding to an approved control reference.
- Add a negative test or static check.
- Propose the smallest safe correction.
- Record evidence and residual risk.

## Evidence

Findings cite code, avoid unsupported claims, include a validation method, and are reviewed by a qualified human.

## Guardrails

Use only synthetic targets. Do not exploit live systems, handle real secrets, weaken controls, or treat generated analysis as an authorization assessment.
