Token cost: structure first, then model choice

  • Structural, model-independent, repeatable: bounded packs per unit, leaf-first, files not transcripts, dry run first
  • manifest.json shows bytes and estimated tokens per pack before any agent runs
  • CLI: /model opus | sonnet | codex, or /model for a selector (docs.devin.ai/cli/models)
  • Default model in ~/.config/devin/config.json (Windows: %APPDATA%\devin\config.json)
  • Fusion pairs a lead model, an effort level, and a sidekick model (docs.devin.ai/desktop/fusion)
  • Availability depends on plan, team restrictions, and administrator allowlists

Writing AGENTS.md without over-constraining

What this repository does

  • Under 40 lines: routing table, short rules, pointer to README when nothing matches
  • Procedures live in skills, one file each; the agent reads long text only for the task at hand
  • One verification command before 'done': python tools/check_repo.py
  • The file's rules are enforced by a tool: routing, links, forbidden terms, skill cap

To scope

  • Which team standards belong in AGENTS.md vs a skill vs CI
  • Constraints that protect people and data stay in AGENTS.md; method goes in skills
  • Who owns edits and how they are reviewed

Windows and remote containers

Windows

  • Tools are standard-library Python; they run on Windows as-is
  • integrations/mcp-hosting.md gives Windows paths; config at %APPDATA%\devin\config.json
  • C lanes need gcc + make: WSL 2 or a native toolchain; lvkit from the offline wheel
  • SSH password prompts may open cmd.exe windows (docs.devin.ai/desktop/advanced)

Remote containers

  • Dev containers on Mac, Windows, Linux, local or over SSH, given Docker + devcontainer.json
  • Open Folder in Container / Reopen in Container / Attach to Running Container
  • SSH needs OpenSSH and Linux hosts; do not install the Microsoft Remote-SSH extensions alongside
  • This repository ships no devcontainer.json yet; one with Python, gcc, make, lvkit would run the whole golden path
