# Feature Development

## Outcome

Turn a synthetic requirement into a reviewed plan, minimal implementation, tests, documentation, and validation evidence.

## Candidate demo

- Clarify acceptance criteria and edge cases.
- Identify the smallest affected surface.
- Review a plan before editing.
- Implement one focused behavior and tests.
- Review the diff and run deterministic checks.

## Evidence

Acceptance criteria map to tests, the diff is focused, checks pass, and remaining uncertainty is documented.

## Guardrails

Use an isolated branch and synthetic repository. Do not deploy, publish, install unapproved dependencies, or expand scope without approval.
