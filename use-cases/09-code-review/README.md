# Code Review

## Outcome

Provide a focused second-pass review that identifies correctness, security, maintainability, and test risks with actionable evidence.

## Candidate demo

- Review a seeded synthetic pull-request diff.
- Prioritize findings by impact and confidence.
- Cite exact files and behavior.
- Distinguish defects from preferences.
- Recommend targeted validation.

## Evidence

Findings are reproducible, prioritized, specific, and independently verified by a human reviewer.

## Guardrails

Keep repository access read-only for the first pass. Do not submit comments, approvals, or external messages without explicit authorization.
