# Outcomes

Use this directory to capture reusable, sanitized results after an enablement session.

- `success-scorecard.md` records evidence against the session criteria.
- `adoption-roadmap.md` outlines a gated path from discovery to broader use.
- `follow-up.md` tracks role-based next steps and unresolved dependencies.
- `lessons-learned.md` records reusable observations without identifying details.

Do not store attendance, account details, environment identifiers, private feedback, recordings, or customer-specific artifacts here.
