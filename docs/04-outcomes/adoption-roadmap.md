# Adoption Roadmap

Progress only when the prior gate has objective evidence and the next boundary is approved.

## Gate 0: Boundary and governance

- Confirm Federal service, identity, data, repository, network, and integration boundaries.
- Define prohibited actions, audit needs, approval roles, and incident handling.
- Select synthetic material.

## Gate 1: Read-only discovery

- Test codebase questions, documentation analysis, and review scenarios.
- Measure answer accuracy, citation quality, review effort, and policy adherence.

## Gate 2: Isolated change

- Use a synthetic or sandboxed repository.
- Require a reviewed plan, focused diff, deterministic tests, and rollback.
- Measure cycle time, defect rate, and human rework.

## Gate 3: Controlled pilot

- Select a small, low-risk workflow and a limited participant group.
- Apply organization policy, logging, training, and support.
- Review results and incidents before expansion.

## Gate 4: Repeatable operating model

- Publish approved patterns, ownership, support, metrics, and review cadence.
- Reassess integrations and data types whenever the boundary changes.

No gate authorizes production access by itself.
