# Approval Checklist

Use role-based approvals and retain evidence only in the approved system of record.

| Decision | Required owner role | Status |
| --- | --- | --- |
| Federal tenant and product distribution approved | Security reviewer | Verify |
| Identity and least-privilege role approved | Identity administrator | Verify |
| Repository and local workspace approved | Repository administrator | Verify |
| Synthetic dataset reviewed | Data owner or security reviewer | Verify |
| Network destinations approved | Network or security reviewer | Verify |
| Each integration and MCP tool approved | Integration owner and security reviewer | Verify |
| Build and test commands approved | Technical reviewer | Verify |
| Recording, screenshots, or presentation assets approved | Communications and security reviewers | Verify |
| Fallback plan approved | Facilitator and security reviewer | Verify |
| Note-taking and retention process approved | Engagement owner | Verify |

Approval for one component does not imply approval for another. Unknown status means the component is excluded.
