# Demo Preflight Checklist

## Before the session

- [ ] Complete the environment readiness checklist.
- [ ] Confirm Federal tenant, identity, and organization policy controls.
- [ ] Confirm every external integration is approved or disabled.
- [ ] Review the repository tree, remotes, history, and working tree.
- [ ] Confirm all content is synthetic and customer-neutral.
- [ ] Run each build, test, lint, and demo command manually.
- [ ] Test the exact prompts and expected evidence.
- [ ] Prepare an offline or static fallback for every scenario.
- [ ] Close unrelated applications, terminals, repositories, and notifications.
- [ ] Remove sensitive shell history and screen content from view without deleting audit records.

## Immediately before each scenario

- [ ] State the desired outcome and stop conditions.
- [ ] Show the scoped workspace and relevant files.
- [ ] Confirm the starting Git status.
- [ ] Start in Plan or Normal mode.
- [ ] Explain which permissions may be requested.
- [ ] Confirm the validation command and expected result.

## After each scenario

- [ ] Review the plan, commands, diff, and validation output.
- [ ] Confirm no unapproved network or integration access occurred.
- [ ] Capture only sanitized evidence.
- [ ] Restore the known safe state if another run is planned.
- [ ] Record feedback without names or system identifiers.
