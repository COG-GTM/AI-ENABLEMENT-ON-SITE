# Discovery Questionnaire

Ask for generic workflow characteristics, not real data or identifying details.

## Workflow

- What outcome is difficult, slow, repetitive, or error-prone today?
- What inputs and tools are normally required?
- Which decisions require human judgment?
- What evidence proves the work is correct?
- Where does the work wait for access, review, or another team?

## Technical shape

- Which languages, frameworks, repository types, and build systems are common?
- Is the work local, multi-repository, infrastructure, data, or documentation focused?
- Which validation commands are deterministic?
- Which steps require network access or an external integration?
- Which steps could be represented with a synthetic repository?

## Governance

- What data classifications may be involved?
- Which actions must always require explicit approval?
- Which repositories, directories, commands, and destinations should be denied?
- What audit evidence is required?
- Who, by role, approves a pilot?

## Prioritization

- How frequently does the task occur?
- What is the current effort or delay?
- What is the consequence of an incorrect result?
- Can a small, isolated scenario demonstrate value?
- What measurable result would justify a follow-up?
