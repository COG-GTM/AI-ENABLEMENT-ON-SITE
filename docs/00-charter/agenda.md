# Modular Agenda

## Opening

- Confirm the session objective and roles.
- Restate the Federal deployment and data boundaries.
- Confirm that only synthetic demonstration material is in scope.
- Explain approval prompts, human review, and stop conditions.

## Product orientation

- Show the repository structure and project rules.
- Contrast Desktop and CLI interaction patterns.
- Demonstrate Plan mode, scoped context, permissions, diff review, and verification.

## Guided scenarios

1. Codebase understanding and targeted questions
2. Planned change with tests and review
3. Debugging or CI failure investigation
4. Documentation, security, or infrastructure scenario selected during discovery

## Use-case discovery

- Capture current workflow, bottleneck, expected outcome, constraints, and evidence.
- Score candidates with the use-case template.
- Select a small number for a controlled follow-up.

## Close

- Review decisions, action items, unresolved questions, and stop conditions.
- Confirm repository sanitization.
- Agree on measurable next steps without making unverified commitments.
