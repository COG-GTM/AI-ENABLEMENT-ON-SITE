# Roles and Responsibilities

| Role | Responsibilities |
| --- | --- |
| Facilitator | Own the agenda, maintain the boundary, narrate the workflow, and stop unsafe activity. |
| Operator | Run Desktop or CLI, keep context scoped, review permissions, and execute only approved steps. |
| Technical reviewer | Review plans, commands, diffs, tests, and technical claims. |
| Security reviewer | Confirm data handling, deployment boundary, integrations, and stop conditions. |
| Note taker | Record only sanitized decisions, actions, evidence, and unanswered questions. |
| Participants | Provide generic workflow context, ask questions, and avoid sharing identifying or sensitive information. |

One person may hold multiple roles, but the operator should not self-approve an unclear boundary decision.
