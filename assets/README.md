# Assets

Store only approved, sanitized, reusable diagrams, screenshots, or presentation assets here.

Before committing an asset:

- Remove names, faces, organizations, project names, locations, account details, endpoints, timestamps, notifications, browser tabs, and unique identifiers.
- Remove embedded metadata.
- Confirm that no source code, log data, ticket content, or architecture is proprietary or sensitive.
- Confirm the asset's license and reuse rights.
- Prefer a purpose-built synthetic diagram over a redacted real screenshot.

Do not add recordings or large binary exports to this repository without repository-administrator approval.
