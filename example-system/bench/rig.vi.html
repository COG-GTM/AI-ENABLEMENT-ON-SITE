Thermal Soak Test.vi

Steps a thermal chamber through a list of setpoints. At each setpoint it lets the chamber settle, reads N uplink packets from the sensor node under test, computes the mean and maximum deviation of the reported temperature and the mean of the stationary Z-axis acceleration, judges the step, and appends a row to the results log.

Block Diagram

[image: Thermal Soak Test_bd.png - omitted in this synthetic export]

Structure, as read off the diagram:

Initialize:
  VISA Open (chamber)  ->  Chamber Set Temp.vi (first setpoint)
  VISA Open (node UART) 115200 8N1
  Open/Create/Replace File (Results log path), write header row

FOR each setpoint in Setpoints (degC)            [For Loop, auto-indexed]
  Chamber Set Temp.vi (setpoint)
  Wait (ms) [Settle time (ms)]
  FOR i = 0 .. Samples per step - 1              [For Loop]
    Read Node Packet.vi -> temp_cc (I16), acc_z (I16)   [16-byte frame, CRC-checked]
    Build Array -> temps, accs
  Compute Stats.vi:
    mean_temp = Mean(temps)                      [DBL]
    mean_temp_cc = Round To Nearest(mean_temp)   [I32]   <-- LabVIEW rounds x.5 to the EVEN integer
    max_dev_cc   = Max( |temps - mean_temp_cc| ) [I32]
    acc_z_mean   = Round To Nearest(Mean(accs))  [I32]
  temp_ok = |mean_temp_cc - setpoint*100| <= Temp tolerance
  imu_ok  = |acc_z_mean - Acc Z nominal| <= Acc Z tolerance
  verdict = Select(temp_ok AND imu_ok, "PASS", "FAIL")
  Log Row.vi -> append CSV row
  Bundle -> Results (auto-indexed out)

Cleanup:
  Chamber Set Temp.vi (25)
  VISA Close x2, Close File
  Simple Error Handler.vi

Case structure on the error wire around each loop body: on error, the step is skipped and the error propagates to error out; no row is logged for a skipped step.
