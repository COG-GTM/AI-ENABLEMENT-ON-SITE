# Personal skill examples

These are starting examples for developer-specific habits, not team repository configuration. Do not
copy `global-skills/` into a team repository or commit installed personal skills.

Verified Devin CLI global skill locations:

- Linux and macOS: `~/.config/devin/skills/<skill-name>/SKILL.md`
- Windows: `%APPDATA%\devin\skills\<skill-name>\SKILL.md`

Install each example as its own `<skill-name>/SKILL.md` directory under the applicable location.
The first supported skill paths and CLI pickup behavior may vary with product builds; confirm on your
build.
